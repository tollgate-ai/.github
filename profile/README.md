# Tollgate

AI writes the code. Locked tests decide.

Tollgate is a plugin for Claude Code. It lets an AI build changes to your software, and keeps each change out of your main branch until it passes tests the AI cannot touch.

- [tollgate](https://github.com/tollgate-ai/tollgate): the plugin and its GitHub workflow.
- [tollgate-ai.github.io](https://github.com/tollgate-ai/tollgate-ai.github.io): the website.

Start and docs: [tollgate-ai.github.io](https://tollgate-ai.github.io/).
